# Hunter Platform

Monorepo inicial da Hunter Platform.

## Requisitos

- Node.js 22 LTS
- pnpm 10

## Instalação no Windows

```powershell
.\INSTALAR.cmd
```

## Instalação manual

```bash
pnpm install
pnpm setup
pnpm dev
```

## Serviços

- Web: http://localhost:3000
- API: http://localhost:3333
- Swagger: http://localhost:3333/docs
- Health: http://localhost:3333/api/health
